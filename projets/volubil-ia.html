Volubil-IA

Une application qui transforme la voix en texte dans n'importe quelle application ouverte sur l'ordinateur : navigateur, traitement de texte, messagerie. Un raccourci démarre l'enregistrement, un second l'arrête, et le texte s'insère directement là où se trouve le curseur. Tout se passe sur la machine, sans clé API ni abonnement.

Le point de départ

L'inspiration vient de Wispr Flow, un outil de dictée vocale payant et fermé. L'idée : construire l'équivalent en gardant le contrôle total sur la confidentialité. Aucune donnée vocale envoyée sur internet, à une exception honnêtement documentée : le tout premier téléchargement du modèle de transcription, une seule fois.

Le codage a été entièrement délégué à un sous-agent piloté par une spécification détaillée, avec deux passes de relecture et de correction avant publication : une façon de tester jusqu'où une conception précise en amont peut porter un développement délégué, sans coder soi-même la moindre ligne.

Comment je l'ai construite

Volubil-IA tourne sur whisper.cpp, un moteur de transcription vocale open source qui fonctionne entièrement en local : pas de compte, pas de clé API, pas de coût récurrent. Le texte capté passe ensuite par un nettoyage automatique (suppression des hésitations, correction des espaces et de la majuscule de départ).

Un mode amélioré, optionnel, ajoute un second passage par un petit modèle de langage local via Ollama : ponctuation automatique, ponctuation dictée à voix haute ("virgule", "à la ligne"), gestion des corrections orales ("on se retrouve à 14h, en fait non, 15h"). Si Ollama n'est pas installé ou ne répond pas, l'application revient automatiquement au mode simple, sans jamais planter.

Un dictionnaire personnel corrige les noms propres ou mots inhabituels que Whisper déforme, avec une correction rapide possible juste après chaque dictée. Comme pour Avion Messager, les installateurs Windows et Mac sont fabriqués automatiquement par GitHub Actions à chaque version, whisper.cpp étant recompilé pour chaque plateforme.

Ce que ça m'a appris

Un bug remonté par un abonné a révélé une limite intéressante : whisper.cpp lit mal les chemins de fichiers contenant des caractères accentués sur Windows (un nom d'utilisateur comme "FrançoisHascoet" faisait planter l'application). Le correctif copie les fichiers concernés vers un dossier de secours neutre avant de les transmettre au moteur de transcription, sans rien changer pour les utilisateurs sans accent dans leur dossier.

Ce projet confirme aussi la valeur d'une vérification de sécurité systématique avant tout partage public : recherche de secrets dans le code et son historique, contrôle des adresses réseau réellement appelées, vérification que les dépendances embarquées (ici whisper-cli) sont bien compilées pour chaque plateforme et non bricolées après coup.

J'ai raconté la construction complète de Volubil-IA (et d'Avion Messager) dans un article Substack, avec les visuels et les vidéos du résultat : Décollage.
