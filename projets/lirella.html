Lirella

Une application web pour cataloguer sa bibliothèque personnelle exactement comme elle est rangée chez soi : par pièce, par étagère. Avec gestion des livres auto-édités que les applications classiques ignorent.

Le contexte

Marine est une lectrice passionnée. Elle possède des centaines de livres, dont beaucoup sont auto-édités — des romans de créateurs indépendants qu'elle suit depuis des années. Son problème : elle ne sait plus ce qu'elle a, ni où c'est rangé.

Les applications existantes comme Gleeph ou LibraryThing sont construites autour des grandes bases de données éditoriales. Elles ignorent les livres auto-édités, non référencés dans leurs catalogues. Et aucune ne permet d'organiser sa collection par emplacement physique réel — salon, chambre, bureau.

Ce que j'ai construit

Lirella est une application web mobile construite avec Claude. Elle permet de créer ses propres bibliothèques (Salon, Chambre, Bureau…) et ses étagères, puis d'y ajouter des livres de deux façons :

Par ISBN : on entre le code barre du livre, l'application récupère automatiquement le titre, l'auteur, la couverture et le résumé via l'API Google Books.

Manuellement : pour les livres auto-édités ou introuvables dans les bases de données, on entre les informations à la main et on ajoute une photo de la couverture.

Toutes les données sont sauvegardées localement sur l'appareil. Pas de compte, pas d'abonnement, pas de données envoyées sur un serveur.

Ce que ça m'a appris

Le vrai défi de Lirella n'était pas technique — c'était de bien comprendre le problème avant de construire. Une application généraliste de gestion de livres existait déjà. Ce qu'il fallait, c'était une application pensée pour quelqu'un qui a des livres auto-édités et qui veut retrouver physiquement ses livres dans sa maison.

Ce projet m'a aussi confirmé l'importance de l'interface sur mobile : une application qu'on utilise d'une main, debout devant une étagère, doit être pensée différemment d'une application de bureau.
