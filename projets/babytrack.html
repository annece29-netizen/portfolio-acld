BabyTrack

Une application mobile gratuite, sans compte et 100% privée, pour suivre le quotidien d'un nouveau-né : alimentation, sommeil et tire-lait. Construite en quelques heures avec Claude, installable sur iPhone et Android comme une vraie app.

Le contexte

Ma belle-fille attendait son premier enfant. Comme beaucoup de jeunes parents, elle cherchait un moyen simple de suivre les tétées, les biberons et les nuits de son bébé, notamment pour répondre aux questions du pédiatre lors des consultations.

Les applications existantes posent toutes le même problème : il faut créer un compte, accepter des conditions d'utilisation floues, et ses données personnelles (et celles de son bébé) se retrouvent sur des serveurs tiers. Certaines sont payantes, d'autres affichent des publicités.

Elle voulait quelque chose de simple, gratuit, et privé. Quelque chose qui reste sur son téléphone.

Ce que j'ai construit

J'ai construit BabyTrack avec Claude : une application web progressive (PWA) en HTML, CSS et JavaScript pur. Aucun serveur, aucune base de données externe. Toutes les données sont stockées localement sur l'appareil via le navigateur.

L'application s'installe sur l'écran d'accueil du téléphone comme une vraie app native, fonctionne hors connexion, et ne demande aucun compte.

Ce qu'elle permet de faire

🍼 Tétées avec chronomètre automatique gauche/droit
🥛 Biberons et tire-lait avec quantités en mL
🌙 Sommeil avec distinction nuit/jour automatique
📊 Statistiques et export PDF mensuel pour le pédiatre

Points forts

100% privée : rien n'est envoyé sur Internet. Toutes les données restent sur l'appareil. Pas de compte, pas d'email, pas de publicité, pas d'abonnement.

Installable : fonctionne comme une vraie application native sur iPhone et Android, directement depuis le navigateur.

Export PDF : un rapport mensuel complet (frise horaire + tableau détaillé) peut être généré et partagé avec le médecin en un clic.

Ce que ça m'a appris

Construire BabyTrack m'a confirmé quelque chose : une application utile n'a pas besoin d'être complexe. Pas de framework, pas de serveur, pas de base de données. Un fichier HTML, du JavaScript, et une personne qui sait exactement ce dont elle a besoin.

Le vrai travail était de comprendre les contraintes réelles : une maman qui allaite à 3h du matin ne veut pas chercher un bouton. L'interface doit être évidente même les yeux mi-clos.

Stack technique

HTML / CSS / JavaScript PWA (Progressive Web App) LocalStorage Claude (construction) Netlify (hébergement)
